# 功能覆盖与分期

基线日期：2026-11-11。Metrolist 参考提交：`e6fea3b36c68841bad21daa6252e1d69ecd3afbe`。本表表示计划覆盖，不表示已经实现。当前所有应用功能均为 `planned`。

| 功能 / 交付范围 | 路线项 | 验收边界 |
| --- | --- | --- |
| 全 C# UI 与业务、.NET 10 / MAUI | M0-02 | 自己维护的应用代码；系统原生绑定另列 |
| YouTube Music 真实音乐源 | M0-05、OPS-01 | 搜索、签名、token、媒体格式、请求头/Range 与有效期 |

| 搜索歌曲、专辑、歌手、视频和歌单 | M1-01 | 视频条目以可用音频播放；来源限制可见 |
| 后台、锁屏和连续换曲 | M1-04/M1-05 | 真实设备、跨曲目与 token 更新 |
| 普通蓝牙车机与方向盘控制 | M1-04 | 系统媒体路由、目标车机支持的命令 |

| 收藏、本地歌单与恢复播放位置 | M1-03 | 数据迁移与启动不擅自外放 |
| 睡眠定时器 | M1-06 | 锁屏与暂停状态下行为明确 |
| 基础缓存与音质选择 | M1-06 | 有界缓存，明确格式和网络条件 |

| 个性化推荐 / quick picks | M2-02 | 来源可用性与登录状态 |
| 歌单导入、排序、数据备份 | M2-03 | 去重、部分失败与恢复 |
| 下载、缓存和离线播放 | M2-04 | 系统后台传输、断网冷启动、离线换曲 |
| 行级与逐词同步歌词 | M2-05 | 歌词来源、seek 和时间偏移 |
| Android 安装包与后台媒体服务 | M3-01 至 M3-04 | 真机、系统通知、焦点与厂商后台行为 |
| Windows / macOS | M4-01 至 M4-03 | 独立平台功能与安装验收 |
| 音量归一化、均衡器 | M5-01 | 音频输出基准和路由切换 |
| 变速、变调、跳过静音 | M5-02 | 音质、时间轴和功耗 |
| 交叉淡化、无缝衔接 | M5-03 | 双播放器资源与中断恢复 |
